# MiraStudio Website

A deployable static website for MiraStudio. Built with plain HTML, CSS, and JavaScript so it can be hosted directly on GitHub Pages without a build step.

## Run locally

```bash
npm start
```

Then open `http://localhost:5173`.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.

## Customize

- Edit `index.html` for content and structure.
- Edit `styles.css` for the visual system.
- Edit `script.js` for interactions.
